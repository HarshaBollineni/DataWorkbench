# Pre-domain GX parity spikes

Archived, non-production verification scripts from the pre-domain Test Lab implementation.
They are retained as historical parity evidence and are not imported by production code or
included in deployment packages.

The scripts resolve the current `source-codes/backend` package for the legacy GX helpers they
exercise. `spike_metrics.py` also references the retired `database` module and is retained only
as historical evidence; it is not a current verification gate.
