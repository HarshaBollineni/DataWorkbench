- RCA sessions can be inspected after restart through persisted `rca_sessions` and `rca_steps`; resuming an interrupted LLM approval loop still requires active in-memory session state.

- Demo reset deletes demo RCA/session/work-product rows and `scope='demo'` object contexts, then reseeds static baseline context memory.
