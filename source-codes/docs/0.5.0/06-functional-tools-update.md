# Functional Code Map — service.py

`functional_tools.xlsx` has one `service.py` sheet with a two-line header: the
first row is `Functional Code Map — service.py`; the second row names the
source file and its scope; row 4 is the six-column header.  The following is
the exact six-column replacement content for rows 5–17.  The workbook itself
is outside this worktree's write boundary, so this markdown is the controlled
FNC-01 hand-off.

| Sl. No. | Important functions | Function purpose | Inputs | Processing | Outputs |
|---:|---|---|---|---|---|
| 1 | `_read_tabular(path: Path)` *(re-verified)* | Import uploaded tabular data. | `path: Path` | Selects CSV, Excel sheets, or CSV files inside ZIP archives and returns parsed tables without domain assumptions. | `dict[str, pandas.DataFrame]` keyed by table/sheet. |
| 2 | `_classify(name, series, target=None)` *(re-verified)* | Infer a generic observed type for one column. | Column name, `pandas.Series`, optional target name. | Delegates to generic value/type signals and uses parse-rate evidence; no business or schema literal drives the result. | Inferred classification such as numerical, datetime, categorical, binary, or text. |
| 3 | `get_inventory(item_id, table=None)` *(re-verified)* | Read the persisted variable-inventory review surface. | Snapshot/item ID; optional table. | Reads inventory, decodes JSON profile/discrepancy fields, adds sample/null/distinct display values and preserves source order. | Review rows for every profiled column. |
| 4 | `put_inventory(item_id, rows, table=None)` *(re-verified)* | Persist user-confirmed type and inventory edits. | Snapshot/item ID, edited inventory rows, optional table. | Upserts edited classifications/notes/roles, records mapping decisions, and persists the post-override confirmed schema map. | Updated inventory rows and snapshot/reference map when applicable. |
| 5 | `create_asset(kind, alias, time_basis, actor=None)` *(renamed from `create_item`)* | Create a durable Dataset or Database asset and version 1. | Asset kind, validated alias, fixed `period`/`none` basis, actor. | Allocates the human-quotable system ID, writes the asset/version/audit rows, and writes the time basis exactly once. | Asset record with system ID, display name, and current version; no snapshot yet. |
| 6 | `add_snapshot(asset_id, intent, actor=None, **period_fields)` *(renamed from `reupload_item`)* | Add one staged or direct immutable snapshot to an existing asset. | Asset ID, `fresh`/`add_period`/`full_replacement` intent, actor, period/label/type-map/storage metadata. | Reuses the delivery seam; preserves prior files and rows; for full replacement creates the next reference-schema version and calls the shared set supersede operation. | Stored snapshot row with asset identity, version, delivery sequence, metadata, and selectability status. |
| 7 | `finalize_item(item_id, target_variable=None, use_case=None)` | Persist optional target/use-case context at asset level. | Snapshot/item ID, optional target variable and use case. | Validates that a data table exists, writes the canonical asset fields, mirrors them on the snapshot, and reprofiles after a target change. | Updated item/snapshot record with asset context. |
| 8 | `save_file(item_id, role, filename, payload)` | Stage a source, dictionary, or schema file and perform structural checks. | Snapshot/item ID, role, filename, file bytes. | Writes the staged file, parses summaries, checks readability/non-empty/header structure and raw headers, updates table totals and starts profiling status. | File metadata plus per-table row/column summary; structural corruption is rejected. |
| 9 | `profile_item(item_id)` | Run the single ingestion/profile pass and orchestrate schema review. | Staged snapshot/item ID. | Reads staged tables once, infers types, computes profiles/warnings/fingerprints, persists mappings and confirmed schema, compares against the current reference schema, and derives status. | Inventory rows, warnings, schema-check event, fingerprints, and `ready`/`needs_review` status. |
| 10 | `_write_table(item_id, table, df)` | Persist one parsed table in the snapshot cache. | Snapshot/item ID, table name, `pandas.DataFrame`. | Sanitizes the physical table name, refuses superseded snapshots, writes SQLite cache data, and contributes snapshot row/column totals. | Persisted table and updated snapshot totals. |
| 11 | `_parse_dictionary(item_id)` | Read and normalize an optional data dictionary. | Snapshot/item ID. | Loads CSV/Excel/JSON dictionary data, normalizes table/column/type declarations, and rejects duplicate declarations within one table. | Nested normalized dictionary metadata or a structural ingestion error. |
| 12 | `_column_profile(series)` | Compute additive profile and AST-17 fingerprint inputs in the existing pass. | One `pandas.Series`. | Calculates null/cardinality/ranges/mean/top-k plus numeric standard deviation, fixed-bin numeric histogram, and low-cardinality sorted-distinct hash using named constants. | Additive profile dictionary consumed by inventory and one fingerprint row per column. |
| 13 | `ingest_summary(item_id, table=None)` | Produce and later retrieve the auditable ingestion/completion payload. | Snapshot/item ID; optional table. | Reads stored status/mappings/warnings and audit events, then assembles asset/label/period/rows/confirmed types/schema change/superseded snapshots/overridden warnings and consequence details. | Complete UPL-27 summary; the same payload is available through the snapshot-id GET endpoint. |

Rows 1–4 are the re-verified functions. Rows 5–13 are the nine refreshed
functions (with the two legacy names mapped to their asset-model replacements).
